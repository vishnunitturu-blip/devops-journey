📌 What is Docker?

Docker is a containerization platform used to build, ship, and run applications.

👉 It allows developers to package:

Application

Dependencies

Libraries
into one container

So it runs same everywhere.

❓ Why Docker is Needed?

Before Docker:

App works on my laptop ❌

Fails on server ❌

Dependency issues ❌

OS differences ❌

With Docker:

Build once

Run anywhere

No dependency conflict

Fast deployment

✅ That’s why companies use Docker.

🧱 What is a Container?

A container is:

Lightweight

Isolated

Runs an application

It shares the host OS kernel, so it is:

Faster than VM

Uses less memory

🖥️ Virtual Machine vs Docker
Feature	Virtual Machine	Docker
OS	Full OS	Shares Host OS
Size	Heavy (GBs)	Light (MBs)
Speed	Slow	Very Fast
Boot Time	Minutes	Seconds
🐳 What is Docker Image?

A Docker Image is a blueprint

Read-only

Used to create containers

Example:

nginx image

ubuntu image

📦 What is Docker Container?

Running instance of an image

You can start / stop / delete it

Image ➜ Container
