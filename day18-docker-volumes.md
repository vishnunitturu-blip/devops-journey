# Day 18 – Docker Volumes

## What is a Docker Volume?
A Docker Volume is used to persist data generated by containers.
Data remains even if the container is removed.

## Why Volumes?
- Containers are temporary
- Data inside containers is lost when deleted
- Volumes store data outside the container lifecycle

## Types of Docker Storage
1. Named Volumes
2. Anonymous Volumes
3. Bind Mounts

## Named Volume
Docker-managed storage, recommended for production.

Create volume:
docker volume create myvolume

Use volume:
docker run -d -v myvolume:/usr/share/nginx/html nginx

## Bind Mount
Maps host directory to container directory.

docker run -d -v $(pwd)/data:/usr/share/nginx/html nginx

## Volume vs Bind Mount
- Volumes: safer, managed by Docker
- Bind mounts: direct host access, used in development
